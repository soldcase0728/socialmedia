# Self-hosted fonts

Latin-subset variable-font `.woff2` files, self-hosted so renders never
depend on network access to Google Fonts (see `src/fonts.ts`).

| File | Family | Style | Weight range |
| ---- | ------ | ----- | ------------ |
| `SpaceGrotesk-latin.woff2` | Space Grotesk | normal | 300–700 |
| `PlayfairDisplay-latin.woff2` | Playfair Display | normal | 400–900 |
| `PlayfairDisplay-latin-italic.woff2` | Playfair Display | italic | 400–900 |
